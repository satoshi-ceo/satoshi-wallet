02 / THE LEGEND

The key existed before the address.

Bitcoin started simpler than most people remember. Before the address formats we use today became standard, early transactions could pay directly to public keys. That matters because a public key is not tied to one blockchain's branding — it comes from the underlying cryptography.

2.1

Are public keys and addresses the same thing?

Not exactly. A public key is a point on an elliptic curve derived from a private key. An address is a chain-specific representation derived from that public key. Bitcoin and Ethereum package the result differently, but both ultimately rely on the same secp256k1 private-key → public-key relationship.

PRIVATE KEY→PUBLIC KEY→CHAIN-SPECIFIC ADDRESS

Different address format. Same underlying key pair.

2.2

Early Bitcoin Days

In Bitcoin's earliest era, pay-to-public-key transactions were common. Satoshi's early activity therefore left public keys visible on-chain — public information that has been preserved for more than a decade.

Once you have a valid secp256k1 public key, deriving its corresponding Ethereum-style address is deterministic. No guessing. No seed phrase. No private-key recovery. Just public cryptographic math.

03 / THE WALLET

The block 9 key.

3.1

Why block 9?

Block 9 is famous because its coinbase output was later used in the first widely recognized person-to-person Bitcoin transfer: Satoshi Nakamoto sent 10 BTC to Hal Finney. It is one of the earliest tangible examples of Satoshi exercising control over a Bitcoin private key.
